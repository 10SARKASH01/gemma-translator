Its matching application source, pinned native source archives, native dependency source, and build instructions are supplied as a **corresponding-source archive alongside the APK**. ## Rebuilding or modifying

Use `build-apk.ps1` on Windows or `build-apk.sh` with a configured Android SDK/JDK on Linux/macOS. Those scripts build the app from its Kotlin source and pinned native runtime. To rebuild the native speech AAR itself, unpack its source archive and dependency archives, set `ANDROID_NDK` to an installed Android NDK, follow the pinned upstream Android build script/workflow, and replace `app/libs/sherpa-onnx-1.13.8.aar` plus the expected checksum in the app build definition. The source package includes the build scripts and all local application tests. A modified APK can be signed with an independent key; Android requires uninstalling the existing app before installing a differently signed build with the same application ID.
